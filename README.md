## 🎮 崩坏:星穹铁道周历

> 每周自动生成 · 版本更新/角色跃迁/活动日历一览无余

---

### 📌 这是什么？

本仓库自动归档每周《崩坏:星穹铁道》的关键游戏事件，包括：
- 🆕 **版本更新** — 大版本更新时间与内容（如周中有更新）
- 🎯 **角色跃迁** — 本周角色卡池与光锥信息
- 🎉 **活动日历** — 各类游戏内活动与限时任务
- ✨ **新立绘/时装** — 新发布的角色外观

### 📂 文件结构

```
hsr-calendar/
├── YYYY/
│   └── Wxx/              # YYYY年 第xx周（周序号）
│       ├── calendar.png   # 本周日历图片
│       └── events.json    # 本周事件数据（JSON格式）
└── README.md
```

### 🔄 自动更新

| 触发时间 | 内容 |
|---------|------|
| 每周六 13:00 (北京时间) | 自动生成下一周日历并推送到仓库 |

### 📊 数据来源

信息按以下优先级采集：
- 🟢 米哈游官方公告
- 🟡 NGA / 百度贴吧 / Bilibili 官方动态
- 🔴 其他社区来源（已标注存疑）

### 🔧 技术栈

- Python 3 日历生成脚本
- GitHub API 自动推送
- OpenClaw 定时任务驱动
